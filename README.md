# Philly Green Clean

Website for Philly Green Clean LLC — air duct, dryer vent, and chimney cleaning in the Philadelphia area. Built with Hugo on the [`hugo-local-biz`](https://github.com/shahar-baharal/hugo-local-biz) theme; deployed by Netlify on every push to `main`.

```bash
hugo server   # → http://localhost:1313 (Hugo extended; fetches the theme module on first run)
```

- Content editing: Sveltia CMS at https://phillygreenclean.com/admin/
- Project docs: [`docs/INDEX.md`](docs/INDEX.md)
